# NEGO - C2C Marketplace

NEGO is a Consumer-to-Consumer (C2C) marketplace built for Nigeria, leveraging Next.js, TypeScript, and Tailwind CSS.

## Key Features
- **Auth & Header**: Login modal, category tabs, cart, and chat badges.
- **Marketplace**: Product grid, filters, and live cart drawer.
- **Watch (TikTok-style Video Feed)**: 15-second product videos with non-blocking "Add to Cart".
- **Chat**: Buyer-seller direct messaging with "Make Offer" negotiation feature.
- **Sell**: Interactive listing form with video upload support.

## Tech Stack
- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
